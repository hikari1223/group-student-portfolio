Who We Are

Five students, one group project

We are five students taking Information Systems at DMMMSU-NLUC, under the College of Information Systems. We come from different backgrounds but we share the same curiosity about how technology works behind the screen.

This portfolio exists to document our individual skills, interests, projects, and experiences as students. Instead of handing in a report that nobody opens, we built a working website — one that runs on a server, answers clicks, and looks the same on a phone.

The whole group worked together on planning the pages, writing the content, building the layout in HTML and CSS, and wiring up the Django backend that serves it.

What we learned

Building this website taught us that programming is only one part of the job. Designing something other people can actually use taught us the rest.

  • How Django handles requests, views, and URLs
  • Using template inheritance so pages stay DRY
  • Organising reusable HTML with an include tag
  • Linking static CSS and images with the static tag
  • Structuring pages with clean, semantic HTML
  • Making a layout responsive on desktop and mobile
  • Working together using Git and GitHub

Our Goals

  • Keep improving our technical skills in web development and information technology.
  • Gain more hands-on experience with Python, Django, and databases.
  • Build a stronger understanding of software development, from planning to testing.
  • Finish future projects that solve real problems for our school or community.
  • Work well as a team and keep documenting what we learn along the way.
