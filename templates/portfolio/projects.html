What building these projects taught us

The hardest part was rarely the coding itself. It was agreeing on the structure, naming files clearly, and making sure everyone’s work still worked together.

  • Plan the pages and URLs before writing any code
  • Use one base template instead of repeating HTML
  • Keep names, spacing, and code style consistent
  • Test the site on a phone as well as a laptop
  • Commit small changes so mistakes are easy to undo
  • Ask each other for help when a page breaks

Next Steps

  • Improve the design of every page on smaller screens.
  • Add more pages and real content from our subjects.
  • Learn how to use a database so the site can store data.
  • Practice Python and Django problem solving outside of class.
